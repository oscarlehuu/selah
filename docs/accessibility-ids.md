# Accessibility identifiers (for XcodeBuildMCP)

> Stable IDs for UI automation. Add to SwiftUI `.accessibilityIdentifier(...)`.

## Onboarding

| ID | Element |
|----|---------|
| `onboarding.continue` | Primary CTA |
| `onboarding.quiz.distance.{busy,guilt,incons,distant}` | Distance cards |
| `onboarding.quiz.desire.{peace,daily,free,know}` | Desire cards |
| `paywall.tier.{weekly,monthly,yearly}` | Tier radio |
| `paywall.subscribe` | Start Selah CTA |
| `paywall.restore` | Restore link |

## Main app

| ID | Element |
|----|---------|
| `tab.today` | Today tab |
| `tab.read` | Read tab |
| `tab.talk` | Talk tab |
| `tab.pray` | Pray tab |
| `tab.journey` | Journey tab |
| `today.settings` | Settings gear |
| `settings.restore` | Restore purchases |

## Paywall gate

| ID | Element |
|----|---------|
| `gate.paywall` | Root paywall container when locked |
| `gate.main` | Main tab shell when subscribed |
